# 证据落地与非核心字段容错：实施交接

## 工作区改动

- `src/ai.ts`：证据使用本次范围的完整 entries 校验，分片不再覆盖原文。依次精确匹配、折叠 Unicode 空白、再归一常见全角/半角及中文标点；每个归一化 UTF-16 单元维护原文半开偏移，返回原文 `slice`，从不返回归一化字符串。全角字母/数字不归一化，避免拓宽成内容改写。
